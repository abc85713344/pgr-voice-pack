## 本次新增（**电脑版**）

### 一、游戏文字跟随（推荐）

游戏配音页现在有四种跟随方式，一次只显示一种的设置：

| 方式 | 说明 |
|---|---|
| **文字跟随**（推荐） | 直接读游戏当前句，**不需要截图、不需要 OCR** |
| 键盘 / 手柄 | 先选中当前句，按键跟随（默认空格） |
| 点按跟随 | 鼠标轻点游戏里的热区，配音跟一句 |
| 顺序播放 | 按共同线台本顺序播放并点击，到分支停住 |

文字跟随分两路，分别连接：

- **普通对白**：游戏停在一条完整正文上，点「连接普通对白」，**无需填入台词**。
- **3D 营地 / 战斗对白**：填入游戏当前完整正文，或在台词页选中对应台词后点「填入选中台词」，再点「连接 3D 对白」。首次连接请选至少 6 个字的完整台词。

连接后新台词会自动定位并播放。同时读取角色名，区分不同角色说出的相同台词；匹配时保留原标点，区分疑问和呼喊。

**其余细节**：

- 快速换句时保留最新句，**不排队补播**被跳过的句子。
- 某句找不到配音或不能确定位置时**只略过该句**，继续监听，后续能匹配的台词自动接上。
- 已验证的对白组件关闭后，不会把残留文字再次当成新台词。
- **支持后台读取与播放** —— 切到浏览器、聊天窗口或展开面板都不会打断配音；其他应用里的鼠标键盘操作不会推进配音。
- 游戏重启或对白组件失效时需要重新连接。

### 二、配音播完后自动点击下一句

在游戏配音页勾选「配音播完后自动点击下一句」，默认等待 **1.5 秒**（可选 1 秒或 2 秒）。

首次使用点「设置自动点击位置」，把「下」字标记拖到游戏对白的点击继续位置。

- 有录音的台词**只有在配音自然播放完毕**后才开始等待，到时核对游戏仍显示原句后点击一次。
- 等待探针读到新台词才请求下一段录音，**不按章节顺序盲播**，也不重复补点。
- 切出游戏或展开面板时配音继续、自动点击暂缓；回到游戏后重新核对正文、角色和点击位置。
- 游戏内主动推进、移动点击位置、隐藏对白都会取消旧句待点击。
- 遇到分支、小节边界、缺音频或无法匹配时**等待手动继续，不会替你选择分支**。

> 请关闭游戏自带的自动播放，避免两边同时推进。

### 三、纯标点台词的处理（2026.10.2.7 起）

已定位的「。。。。。。」「……」「？！」等**纯标点台词**，如果没有附带录音，会停留约 **1.2 秒**后核对并点击一次；已有录音则照常播放。

普通文字、动作说明、空白正文，以及已声明录音但文件丢失的情况仍按缺音处理。正文与角色相同、对应多个位置的标点**不猜测**，请手动确认。

## 首次使用要先选游戏位置

这一版开始需要让软件知道战双装在哪：

1. 打开播放器 → **设置 → 游戏与配音包 → 战双游戏位置 → 选择战双游戏文件夹**
2. 选择**直接放着 `PGR.exe` 的那个文件夹**（同一层通常还有 `PGR_Data` 文件夹、`GameAssembly.dll`、`UnityPlayer.dll`）
3. **不要**选 `PGR_Data`、配音包文件夹，也不要只选整个磁盘

> 如果选的是放着 `launcher.exe` 的外层安装目录，软件会自动往下一层找；只找到一份完整游戏时会自动定位。找到多份时请进入要用的那一份再选。

游戏没打开时也能保存目录。之后正常从启动器进游戏，播放器会连接所选目录正在运行的游戏；也可以点「自动连接已打开的战双」。**不需要**把播放器或配音包放进游戏目录。

## 隐私与安全

- 本程序**不预设任何人的战双安装位置**，也不包含制作者的设置、存档、游戏文件或账号信息。每位用户在自己的电脑上选择一次即可。
- 文本追踪**直接从游戏进程读取文字和组件状态**：不截图、不调用 OCR、**不向游戏内存写入内容、不注入代码**。
- 开启自动下一句后，通过 Windows 发送一次普通鼠标点击。
- 安装位置记录保存在本机用户设置中，**不随通用程序分享**。

## 系统要求

- Windows 10 / 11 **x64**。本次发布没有 x86 或 ARM 版。
- 文字跟随**不需要 OCR，也不要求独显或 CUDA**；只有使用 F9 截图定位时才需要 OCR 组件，建议预留约 1 GB 可用内存。
- **无需安装 Python、.NET 运行时**，也无需下载或配置 OCR 模型。

## 已知限制

- 游戏更新或不同客户端的组件布局可能不同；**遇到尚未适配的布局会停止连接并提示**。目前已在兼容的 Windows 原生客户端验证普通对白和第 29 章的一类 3D 对白，**不代表所有视频字幕或其他入口都已适配**。
- 管理员权限游戏与普通权限播放器并行时，Windows 可能限制按键读取。若遇到按键不跟随，可右键 `PgrVoice.exe` 选择「以管理员身份运行」，或让游戏改用普通权限，**关键是保持两边权限一致**。
- 未绑定节点包含纯视觉符号、未核实正文等，**不能全部理解为缺少可读录音**；本次交付**不宣称配音已 100% 补齐**。
- 音频内容沿用制作端已接入结果，**没有对十余万句重新逐句试听**；已逐个检查被引用音频存在、非空且 WAV 头可读。
- 只在制作机本机 Windows 11 x64 完成了界面与独立解压验证，**尚未在第二台全新 Windows 电脑上实测**。
