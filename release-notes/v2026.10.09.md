## 电脑版 2026.10.9.9 本次更新

### 设置系统的完整检查与修复

本轮对**全部设置项**做了一次系统性核对：**32 组设置入口、43 个配置字段**，逐项检查保存、恢复与播放联动。

修好的问题：

- **设置下拉框和音量滑块的原生键盘操作会误触发剧情翻句** —— 现在 Esc 先关闭列表，键盘操作不再穿透到播放。
- **旧配置兼容**：补齐显式空字段与异常数值的处理。有 **3 份原本会导致旧版启动失败的配置文件**，在最终 EXE 中均能正常启动并自然退出，合法偏好完整保留。

### 本次验证范围（如实）

- 最终 EXE 实际重跑 **4 组 173 项**；另 15 组 919 项因 final2→final3 之间仅有隔离检查器变化、且逐文件源码一致，按差异链复用，**不声称全部在最终 EXE 上重跑**。
- 3 份坏配置实际启动检查 27 项、中文空格路径解压空库启动、37 个 ZIP 成员 CRC/SHA、新目录 **625 个 OCR 文件**及实图识别「那是文明的火种」均通过。
- 隔离 WPF 与受控输入检查**不等于**真实战双全库通关、实体手柄验证或人耳听审。

## 安卓版 0.3.34（试验版）本次更新

> ⚠️ 这是**试验版**。相对稳定版 0.3.22 多了后续所有新功能，验证范围以设备受控测试为主，**未在 ARM64 真机上做完整通关验证**。

### 常规点按分支衔接

修复了自动跟随在普通分支处的衔接问题：

- 在玩家**一次手势之前**冻结已核实的纯控制链，成功后**零额外游戏点击**跨过 return / merge，直达唯一正文或下一选项。
- `SourceChoice` 与 `ConfirmedBranch` 明确各自的续接方式（`AutoPlayback` 或 `ClickFollow`）；纯点按恢复原跟随框，**不擅自启动自动播放**。
- 连续选项仍逐次等待玩家确认；未知连接、条件分支、缺音情况保持等待核对。
- 失焦、改设置、位置变化都会撤销旧票据；已保存的区域设置不会被清掉。

### 设置系统检查

建立 **20 个模型字段 / 43 组 UI 入口**清单，并修复：

- 显式 `null` 字典兼容
- 总设置与听书偏好保存失败时的**独立警告**（听书时可见，可查看全文；保存成功才清除对应警告）
- 捕获按钮状态与分支模式说明

### 本次验证范围（如实）

- 最终 API 35 x64 模拟器受控 Canvas / 合成音 **7 场景 54 项**实际重跑，关键卡片与跟随框已目视截图核对。
- 覆盖安装保留 64 份测试 JSON。
- **不是 ARM64 手机、不是真实战双全库、不是人耳听审**；设置修复的设备复测单独计数，不与旧测试数合并。

## 已知限制

- **文字跟随依赖具体客户端的内存布局**。游戏更新或换客户端后可能需要重新适配；遇到未适配的布局会**停止连接并提示**，不会读出错乱内容。
- **需要管理员权限**：程序以管理员权限运行，每次启动都会经过 UAC（除非系统关闭了 UAC）。**标准账户在没有管理员密码时无法启动。**
- 管理员权限的窗口**收不到**从普通权限资源管理器拖入的文件（Windows UIPI 限制）。
- 未绑定节点包含纯视觉符号、未核实正文等，**不能全部理解为缺少可读录音**；本次交付**不宣称配音已 100% 补齐**。
- 只在制作机本机完成验证，**尚未在第二台全新 Windows 电脑上实测**。
