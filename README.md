## 三步就能开始

1. 解压播放器包（GitHub 上叫 `01-player-windows-x64.zip`，网盘里叫 `01-播放器-Windows-x64.zip`，是同一个文件）。
2. 下载你要玩的章节 ZIP，**解压到同一个位置**，合并同名的「战双剧情配音播放器」文件夹。要用 F9 截图定位，就再解压 OCR 包，同样合并进去。
3. 双击里面的 `PgrVoice.exe`。

正确结构如下，**注意不要多套一层同名文件夹**：

```text
战双剧情配音播放器/
  PgrVoice.exe
  Assets/
  ocr/                     ← 可选，只在下过 OCR 包时才有
    PgrOcr.exe
    models/
    _internal/
  配音包/
    第29章_源解信标/
      pack.json
      audio/
    第30章_镜像星尘/
      pack.json
      audio/
```

请在资源管理器里**完整解压后再运行，不要在压缩包预览窗口里直接双击程序**。

第一次打开后：选章节和小章节 → 在设置中绑定正在运行的游戏窗口 → 确认推进键和游戏一致。启动、恢复进度和浏览台词都**不会自行播放**，按一次推进键才播下一句。

> 如果游戏以**管理员权限**运行，Windows 可能限制普通权限播放器读取按键。遇到按键不跟随，先让游戏也以普通权限运行；期间鼠标点击配音面板仍然可用。

## 核对下载是否完整

全部 59 个章节 ZIP 都做过 CRC 读取校验并记录了 SHA256（另有播放器、可选 OCR 和索引补充包）。完整清单在 [`文件校验.json`](文件校验.json)，逐文件记录在 [`校验记录/`](校验记录)。

> 清单里的键用的是**中文原名**（如 `01-播放器-Windows-x64.zip`）；GitHub 附件叫 `01-player-windows-x64.zip`，**两者 SHA256 相同**，可以直接对照。

在 PowerShell 里算一个文件的哈希：

```powershell
Get-FileHash .\01-播放器-Windows-x64.zip -Algorithm SHA256
```

把结果和 `文件校验.json` 里对应的 `sha256` 对比即可。

## 常见问题

**按键不跟随，或 F1 / F9 按了没反应？** 多半是**权限不一致**：游戏以管理员权限运行，而播放器是普通权限，Windows 会阻止低权限程序读取高权限窗口的按键。两种解法任选其一：

- 右键 `PgrVoice.exe` → **以管理员身份运行**（让播放器和游戏一样高权限）
- 或把游戏改成普通权限运行

**关键是两边权限保持一致** —— 一边管理员、一边普通时，按键最容易失效。程序设置页会显示播放器权限，绑定游戏后也会提示游戏是否为管理员权限，可用来对照。

**按一次「下一句」前进了两句，或者按空格时播放器动了、游戏没动？** 这是 **2026.09.24 版**的问题，**2026.09.27 版已修复**，更新到最新版即可。想换一种更稳的跟随方式，可以在设置页打开「显示「下一句」点击热区」：把它拖到游戏里“点击继续”的位置，之后点它就能让游戏和配音一起推进，**点选项、技能等别处不会跟随**。

**双击后没看到播放器？** 确认已完整解压，查看任务栏或屏幕边缘的小悬浮球。仍无法启动时，看 `%LOCALAPPDATA%\PgrStoryVoice\player.log`。

**按 F9 没反应？** 确认游戏窗口已绑定、游戏没有最小化、当前小章节选对了，并检查 `ocr/` 下是否有 `PgrOcr.exe`、`models`、`_internal`。手动播放和 F1 分支**不依赖 OCR**。

**OCR 报缺少 `VCRUNTIME` / `MSVCP`？** 按[微软官方说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)安装最新受支持的 **x64** Visual C++ 运行库。不要从非官方站点下载单个 DLL。

**游戏里能选的分支，软件提示前置未完成？** 按 F1 打开本节完整分支目录，按游戏当前画面定位并确认相同选项，**不用重读前面的剧情**。

更多问题见[配置要求与使用指南](配置要求与使用指南.md)，里面带界面截图。
